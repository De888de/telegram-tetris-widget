👾 ЧТО ЭТО?
Это полноценный Тетрис, который работает прямо внутри сообщения Telegram. Никаких скачиваний, установок и переходов по ссылкам. Нажал кнопку — и играешь.

Особенности:

🎨 Квадраты 3x3 — собирай блоки одного цвета, чтобы сжечь их и получить бонусные очки!

🟦 7 классических фигур (I, O, T, S, Z, J, L) — каждая имеет свой уникальный цвет.

⚡ Ускорение — с каждой сгоревшей линией фигуры падают быстрее.

👥 Счётчик игроков — бот запоминает, сколько людей уже попробовали игру.

🏆 Система очков — за линии и квадраты дают разные бонусы.

🚀 КАК ЗАПУСТИТЬ У СЕБЯ
Требования
Node.js 20+

Токен от @BotFather

Установка
bash
# 1. Клонируй репозиторий
git clone https://github.com/De888de/telegram-tetris-widget.git
cd telegram-tetris-widget

# 2. Установи зависимости
npm install

# 3. Создай .env и вставь токен
echo "BOT_TOKEN=твой_токен_из_BotFather" > .env

# 4. Запусти бота
npm run dev
Использование
/start — приветствие

/tetris — запустить игру (работает только в личных сообщениях)

🛠️ ТЕХНОЛОГИИ
Bot API 10.4 — новейшие HTML-виджеты (ноябрь 2026).

puregram — быстрая и лёгкая обёртка над Telegram Bot API.

HTML/CSS/JS — рендеринг игры внутри сообщения.

Node.js — обработка запросов и хранение статистики игроков.

📜 ПРАВИЛА ИГРЫ
Линии. Собирай горизонтальные линии — получаешь очки, а линия исчезает.

Квадраты 3x3. Собирай одинаковые цвета в квадрат 3x3 — он исчезает с бонусом +500 очков.

Гравитация. Всё, что висело в воздухе, падает вниз.

Проигрыш. Игра заканчивается, когда новый блок не может появиться на поле.
